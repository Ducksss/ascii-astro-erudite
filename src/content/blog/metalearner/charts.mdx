The MetaLearner chart gallery let a reader try a chart and read its explanation on the same page. I handed over nine demos across six categories, with content for English, Spanish and Portuguese, under the `/graphs/*` routes.

Each detail page combined a live demo, sample code, related navigation and an explanation of when the chart type was useful. Before-and-after examples described the changes rather than asking the reader to judge them from appearance alone. The [gallery walkthrough](https://www.youtube.com/watch?v=vEYGuY5jr-U) shows the interactions.

## A stock chart as an interaction example

The S&P 500 chart fetched data through `/api/yfinance` and used D3 for zooming and panning. It also offered time-range controls, hover inspection and a vertical axis that adjusted to the visible data.

_The detail page shows the chart, the changes and the intended use together. The example changes both the data source and the interface, so its before-and-after images are not a comparison of the same dataset._

A time series has several levels of detail, and each control exposes a different one:

| Interaction               | What it lets you inspect                                               |
| ------------------------- | ---------------------------------------------------------------------- |
| Change the time range     | Read a day or a longer period without fitting all of it into one view  |
| Zoom and pan              | Concentrate on a section of the timeline                               |
| Hover                     | Read a point's value and context rather than estimate it from the axis |
| Rescale the vertical axis | See variation within the selected part of the series                   |

For example, a narrow dip can disappear into a long history when many points occupy the same few pixels. Zooming gives that section more horizontal space, and hovering lets you inspect the values around it. Changing the range answers a broader question about whether that dip belongs to a longer trend.

## The axis changes the apparent movement

Dynamic vertical scaling makes small movements visible, but it also changes the frame of reference. A line can look dramatic in a tightly scaled view even when the absolute change is small.

That is a tradeoff to keep in mind when inspecting the stock-chart demo. Compare the axis labels and time range as well as the shape of the line, especially after zooming. The chart gives more detail about a selected interval, but the picture alone no longer tells you how large that movement is relative to a wider period.

The same interaction problem occurs in demand and forecast charts. A user may want to investigate a short interval without losing track of the scale of the larger series. The gallery demonstrated an interaction pattern that could be considered for those views, rather than establishing that it had been integrated into every forecasting screen.

## Explaining the behaviour beside the demo

Other improvements included legends, tooltip emphasis, cursor tracking and categorical grouping. Carl's early feedback specifically called out “the tooltips and the categorical grouping on focus”, which is more useful detail than a general preference for the new appearance.

The reusable pages were driven by chart configuration and shared routing, with D3 handling chart behaviour, Framer Motion handling transitions and i18next supporting the content. The value of that structure was practical: a chart's demo, explanation and related links could follow the same page pattern without each becoming a separate page design.

Mobile-friendly frontend work accompanied the gallery. A narrower plot leaves less room for labels and close-together points, which makes inspection controls and readable explanations especially relevant when reviewing a responsive chart.
